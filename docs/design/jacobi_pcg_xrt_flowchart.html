Project-XPlus Jacobi-PCG XRT 流程图

当前默认实现是单顶层 pcg_control_kernel：host 只启动一次 kernel，PCG 主循环、alpha / beta、收敛和 breakdown 判断都在 FPGA 上完成。

输入块 功能描述块 输出块

Host 侧流程

Host: 读取数据、构造预条件器和分块矩阵
输入 dataset_dir, tau, max_iters
功能描述 加载 CSR 矩阵、右端向量和初始解，CPU 侧构造 m_inv = 1 / diag(A)，同时把 CSR 转成按 x-window 分组的 4x4 block/bitmap SpMV 格式。
输出 a_win_row_ptr, a_win_col_idx, a_win_blocks, b, x0, m_inv, effective_max_iters
Host: 创建 XRT 对象和 BO
输入 xclbin, a_win_row_ptr, a_win_col_idx, a_win_blocks, b, x0, m_inv
功能描述 下载 xclbin，创建 pcg_control_kernel，分配并同步输入 BO。
输出 a_win_row_ptr_bo, a_win_col_idx_bo, a_win_blocks_bo, b_bo, m_inv_bo, x_bo, r_bo, z_bo, p_bo, ap_bo, metrics_bo, status_bo
Host: 启动一次 pcg_control_kernel
输入 所有 BO，tau, effective_max_iters, n
功能描述 设置 kernel 参数，调用 pcg_run.start() 和 pcg_run.wait()。host 在等待期间不参与每轮 PCG 控制。
输出 FPGA 写回后的 x_bo, metrics_bo, status_bo

FPGA 内部流程: pcg_control_kernel

Kernel: HBM 常驻向量状态
输入 x_bo, r_bo, z_bo, p_bo, ap_bo
功能描述 x/r/z/p/ap 都常驻 HBM。kernel 不再把整条向量缓存进 BRAM，只在每个循环阶段原地读写这些 BO。
输出 HBM 上的 PCG 向量状态
Kernel: 初始化 SpMV
输入 a_win_row_ptr, a_win_col_idx, a_win_blocks, x_bo
功能描述 用按 x-window 分组的 4x4 block/bitmap SpMV 计算 ax0 = A * x0。这里的 ap_bo 临时承载 ax0。
输出 ap_bo = ax0
Kernel: 初始化 r/z/p/metrics
输入 b, ap_bo=ax0, m_inv
功能描述 计算 r0=b-ax0，z0=M^-1*r0，p0=z0，rz0=r0^T z0，rr0=r0^T r0。
输出 r_bo, z_bo, p_bo, rz, rr
循环入口判断
输入 rr, tau, iteration, max_iters
功能描述 判断是否已收敛或是否已经达到迭代上限。
输出 继续迭代，或写 status=converged/max_iter
出口: converged / max_iter
输入 rr <= tau 或 iteration == max_iters
功能描述 设置最终状态。
输出 status, iterations
Kernel: SpMV 和 dot
输入 a_win_row_ptr, a_win_col_idx, a_win_blocks, p_bo
功能描述 用按 x-window 分组的 4x4 block/bitmap SpMV 计算 ap = A*p，再计算 pAp = p^T ap。
输出 ap_bo, p_ap
Breakdown 判断
输入 p_ap, rz
功能描述 检查 pAp 或 rz 是否为 NaN 或接近 0。
输出 继续计算 alpha，或写 status=breakdown
出口: breakdown
输入 非法 p_ap 或 rz
功能描述 停止迭代。
输出 status=2
Kernel: alpha 更新 x/r/z
输入 rz, p_ap, x_bo, r_bo, p_bo, ap_bo, m_inv
功能描述 计算 alpha=rz/pAp，更新 x=x+alpha*p，r=r-alpha*ap，z=M^-1*r，并归约新 rz/rr。
输出 x_bo, r_bo, z_bo, rz_new, rr_new, alpha
收敛及时出口判断
输入 rr_new, tau
功能描述 如果 rr_new <= tau，kernel 立即退出，不再计算本轮 beta/update_p。
输出 继续更新方向，或写 status=converged
出口: converged
输入 rr_new <= tau
功能描述 停止迭代。
输出 status=0, iterations
Kernel: beta 更新 p
输入 rz_new, rz_old, z_bo, p_bo
功能描述 计算 beta=rz_new/rz_old，更新 p=z+beta*p。随后沿左侧回环进入下一轮循环入口判断。
输出 p_bo, rz=rz_new, rr=rr_new
Kernel: 写回标量状态
输入 rz, rr, p_ap, alpha, status, iterations
功能描述 最终解已经在 x_bo 原地更新，这里只写回摘要标量和状态。
输出 x_bo, metrics_bo=[rz, rr, pAp, alpha], status_bo=[status, iterations]

Host 回读与校验

Host: 回读结果
输入 FPGA 写回后的 x_bo, metrics_bo, status_bo
功能描述 同步 device 到 host，解析 status_code、迭代次数和最终 rr。
输出 x_final, rr, status, iterations
Host: CPU 残差与 golden 校验
输入 x_final, CSR 矩阵, b, CPU golden
功能描述 CPU 侧重新计算残差，比较 FPGA 解和 golden 解，并输出 txt/json/html 报告。
输出 residual_abs, residual_rel, max_abs_diff, 报告文件

旧的 spmv_csr_kernel、init_pcg_kernel、dot_kernel、update_xrz_kernel、update_p_kernel 仍保留为拆分实现参考；默认 xclbin 只链接 pcg_control_kernel。
