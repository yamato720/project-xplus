## 版本口径

定位：

```text
FPGA: 只做 Cuper SpMV
host: 做 PCG loop、dot、alpha/beta、x/r/z/p 更新、收敛判断
```

主要源码：


- Kernel: `Cuper`
- 16 路 `Matrix_data_0..15`，端口宽度 512 bit。
- `Matrix_data_0..15 -> HBM[0..15]`
- `X -> HBM[0]`
- `Y_out -> HBM[1]`
- `DATA_CLK`: 174 MHz

## 运行示例

TAPA Cuper + host PCG：

```bash
make cuper-tapa-pcg-host

make run-cuper-pcg-tapa \
  DATASET=/path/to/dataset \
  BITFILE=/path/to/Project-XPlus/395bitstream/Cuper_2022.xclbin \
  TAU=1e-8 \
  MAX_ITERS=1000
```

Control kernel full PCG：

```bash
make cuper-control-xrt-host

./build/xplus_cuper_control_xrt_host \
  /path/to/Project-XPlus/395bitstream/cuper_pcg_control_fullcuper_20260522.xclbin \
  /path/to/dataset \
  --tau 1e-8 \
  --max-iters 1000
```

## 对比记录口径

每个数据集每版都记录：

```text
dataset
n / nnz
tau
max_iters
实际 iterations
总运行时间
kernel/SpMV 时间
host preprocessing 时间是否计入
residual_abs / residual_rel
status
```

建议同时保留端到端时间和 kernel 时间。`Cuper_2022.xclbin` 的 PCG 在 host，host CPU 和 PCIe/XRT 往返会影响总时间；control 版 PCG 在 FPGA，更适合观察多迭代场景下减少 host 往返后的收益。
